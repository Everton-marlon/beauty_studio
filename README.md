# Beauty Studio

Aplicação web para apoiar a gestão de um estúdio de beleza.

## Visão geral

O projeto reúne uma interface para organizar a rotina do studio, com foco em informações administrativas, atendimentos e acompanhamento do negócio.

## Como executar

Por enquanto, não há instalação necessária. Abra o arquivo `gestao.html` em um navegador para visualizar a aplicação.

## Estrutura principal

- `studio.html` — página principal do studio.
- `gestao.html` — painel de gestão.
- `portal-cliente.html` — área da cliente.
- `ficha-anamnese.html` — formulário de anamnese.
- `assets/images/` — imagens utilizadas no projeto.
- `css/` — estilos personalizados de cada página.
